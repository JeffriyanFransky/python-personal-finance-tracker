# 💰 Personal Finance Tracker

A simple personal finance tracking web application built with **Python and Streamlit**.

This project is part of my journey to learn Python development and build practical applications for my software development portfolio.

## 📌 About the Project

Personal Finance Tracker is a beginner-friendly web application designed to help users manage and monitor their personal finances.

The application provides a simple dashboard displaying income, expenses, and balance information, along with a form for entering financial transactions.

**Project Status:** 🚧 Work in Progress

Currently, the application uses sample financial data and provides a basic transaction input interface. Persistent data storage will be added in future updates.

## 🚀 Getting Started

### 1. Clone the Repository
git clone https://github.com/USERNAME/python-personal-finance-tracker.git

### 2. Navigate to the Project Directory
cd python-personal-finance-tracker

### 3. Create a Virtual Environment
python -m venv .venv

### 4. Activate the Virtual Environment

On Windows PowerShell:
.\.venv\Scripts\Activate.ps1

On macOS or Linux:
source .venv/bin/activate

### 5. Install Dependencies
python -m pip install -r requirements.txt

### 6. Run the Application
python -m streamlit run app.py

Open the application in your browser:

http://localhost:8501
